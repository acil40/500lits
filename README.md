# Feuille de consommation — Résidence 500 Lits

Site statique (pas de build). Connexion : `hassad` / `5420`.

## Cloudflare Pages — Direct Upload

1. Télécharger `500lits-pages-direct.zip`
2. Cloudflare Dashboard → Pages → projet **500lits** (ou créer un projet)
3. **Direct Upload** du zip
4. Framework preset : **None**
5. Build command : **vide**
6. Output directory : **vide** (index.html est à la racine du zip)

Ne pas zipper le dossier `docs/` lui-même : `index.html` doit être à la racine du zip.
